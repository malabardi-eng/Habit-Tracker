Habit Tracker — sorgente del sito

Questo index.html è il codice sorgente completo del sito da pubblicare su:
https://malabardi-eng.github.io/habit-tracker/

Repository GitHub:
https://github.com/malabardi-eng/habit-tracker

Per modificarlo in futuro: aggiorna questo file (o chiedi a Claude di farlo),
poi carica la nuova versione sul repo GitHub (via web o via git push) perché
le modifiche appaiano sul sito pubblicato.

I dati (Sport, Studio, Ufficio, Diario) non sono in questo file: vengono letti
e scritti in tempo reale dallo stesso progetto Supabase di "Le mie finanze",
ma in tabelle separate con prefisso habit_ (vedi schema.sql in questa cartella
per la struttura esatta). Qualunque copia di questo index.html mostrerà
sempre gli stessi dati veri e aggiornati.
